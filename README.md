# BLOCK-VERSE

An original 3D sandbox-platformer starter built with Godot 4. Walk, jump, explore a starter obby, and experiment with a simple build mode.

## Controls
- WASD: move
- Mouse: look around (click the game window to capture mouse; Esc releases it)
- Space: jump
- B: toggle build mode
- Left click in build mode: place a block

## Windows build
GitHub Actions builds the Windows desktop export. Open the **Actions** tab and download the `BLOCK-VERSE-Windows` artifact from a successful run. The ZIP contains the executable and its `.pck` data file.

## Run locally
Install Godot 4.4.1, open `project.godot`, then press F6/F5. To export locally, install the matching Godot export templates and use the Windows Desktop preset.

This is an early single-player prototype, not a full multiplayer Roblox replacement yet.
